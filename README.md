## ✨ Features

- 📸 **Bulk Batch Processing** — Upload multiple images at once and generate unified overlays effortlessly.
- 🗺️ **Interactive Leaflet Map** — Pinpoint exact latitude, longitude, and altitude with real-time map controls.
- 🔤 **Tesseract OCR Integration** — Automatically read and extract text from uploaded images.
- ✂️ **Cropper.js Tooling** — Precise image cropping and orientation correction before stamping.
- 🏷️ **Customizable Watermarks & Overlays** — Tailor timestamp, location coordinates, pitch, roll, and custom project notes.
- 📦 **ZIP Package Export** — Download all processed images in a single batch archive with JSZip.
- 🔒 **Privacy-First & Offline Capable** — Runs entirely inside your browser. No files are uploaded to any server.

## 🚀 Live Demo & Usage

Open index.html directly in any modern browser:

``bash
# Clone repository
git clone https://github.com/devildai/AngleBulk.git
cd AngleBulk

# Open in browser
start index.html
``
